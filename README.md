# Recruitment-Analysis-Dashboard
🚀 Recruitment Analysis Dashboard | Business Insights 360
🌟 Project Overview

The Recruitment Analysis Dashboard is a powerful HR analytics solution built to streamline hiring insights and recruitment performance tracking. This dashboard helps HR teams and business leaders monitor hiring progress, recruiter efficiency, application flow, and workforce planning through interactive visualizations and KPI-driven analytics.

📊 Dashboard Highlights

✨ Real-Time Recruitment Tracking
Monitor open positions, applications, hires, and hiring completion percentage instantly.

📈 Hiring Trend Analysis
Analyze weekly hiring progress and recruitment timelines with dynamic charts.

👨‍💼 Recruiter Performance Insights
Track recruiter-wise hiring efficiency and candidate conversion metrics.

🏢 Department & Location Analysis
Filter recruitment data by department, location, role, and job level.

📋 Detailed Candidate Pipeline
View application status, open days, balance hires, and KPI indicators in one place.

🎯 KPI-Based Decision Making
Identify over-hiring, under-hiring, and successful hiring trends effectively.
