📌 About the Project

The Recruitment Analysis Dashboard is an interactive HR analytics solution developed to monitor and optimize the recruitment process. It provides valuable insights into hiring performance, recruiter productivity, application flow, and workforce planning. The dashboard enables organizations to make faster and smarter hiring decisions using real-time data visualization and KPI tracking.

🎯 Objectives
📊 Analyze recruitment and hiring performance
👨‍💼 Track recruiter efficiency and hiring completion
📈 Monitor applications, hires, and open positions
🏢 Evaluate department-wise and location-wise hiring trends
⚡ Improve workforce planning and decision-making
🎯 Identify hiring gaps and recruitment bottlenecks
🌟 Dashboard Highlights

✨ Interactive recruitment analytics dashboard
📌 Real-time KPI monitoring and hiring insights
📈 Weekly hiring timeline visualization
👥 Recruiter performance tracking
🏢 Department and business-wise hiring analysis
📋 Detailed recruitment status and candidate pipeline
