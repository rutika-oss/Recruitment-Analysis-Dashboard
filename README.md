📌 Recruitment Analysis Dashboard | Power BI Project

The Recruitment Analysis Dashboard is an interactive HR analytics solution designed to monitor and optimize the recruitment process. It provides actionable insights into hiring performance, recruiter productivity, application flow, and workforce planning.

🎯 Key Objectives • Analyze recruitment and hiring performance • Track recruiter efficiency and hiring completion • Monitor applications, hires, and open positions • Evaluate department-wise and location-wise hiring trends • Improve workforce planning and decision-making • Identify recruitment bottlenecks and hiring gaps

🌟 Dashboard Highlights • Interactive recruitment analytics dashboard • Real-time KPI monitoring and hiring insights • Weekly hiring timeline visualization • Recruiter performance tracking • Department-wise hiring analysis • Candidate pipeline and recruitment status overview

🛠️ Tools & Technologies Used • Power BI – Dashboard Development & Visualization • SQL – Data Extraction & Querying • Excel / CSV – Data Source Management • Python – Data Cleaning & Processing • DAX – KPI Calculations & Measures
